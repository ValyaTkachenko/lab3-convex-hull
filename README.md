# Лабораторна робота №3. Опукла оболонка

**Виконала:** Ткаченко Валентина, група КМ-41

**Варіант:** DS6

Програма на Python знаходить опуклу оболонку множини точок з датасету DS6 алгоритмом Ендрю (Monotone Chain), зберігає її в окремий файл і відображає синіми відрізками разом з точками на полотні 960×540. Бібліотека: Pillow.

## Файли
- [lab3_DS6.ipynb](lab3_DS6.ipynb) — ноутбук Google Colab з програмою
- [lab3_ds6.py](lab3_ds6.py) — текст програми
- [DS6.txt](DS6.txt) — вихідний датасет

## Запуск
```
pip install pillow
python lab3_ds6.py
```
